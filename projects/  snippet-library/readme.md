
# Snippet Library

## Objetivo

Centralizar snippets reutilizáveis utilizados em testes A/B no VWO.

O objetivo é evitar reescrever soluções recorrentes e padronizar implementações.

---

## Categorias

- DOM
- CSS
- Events
- Analytics
- SPA
- Resize
- Helpers
- Components

---

## Estrutura de cada snippet

Todo snippet deve conter:

- Objetivo
- Quando utilizar
- Quando não utilizar
- Riscos
- Exemplo de uso
- Código
- Testes onde foi utilizado
- Melhorias futuras

---

## Regras

- JavaScript Vanilla
- Compatível com VWO
- Sem jQuery
- Sem frameworks
- Sem comentários
- Compatível com SPA quando necessário
- Idempotente
- Reutilizável
- Fácil manutenção
