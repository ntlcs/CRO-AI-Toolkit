# CRO AI Toolkit

Um conjunto de ferramentas para aumentar a produtividade no desenvolvimento de testes A/B utilizando VWO.

O objetivo deste projeto é reduzir tarefas repetitivas, padronizar o desenvolvimento e automatizar validações técnicas utilizadas no dia a dia de um desenvolvedor CRO.

---

# Objetivos

- Reduzir o tempo de desenvolvimento.
- Padronizar a criação de testes VWO.
- Automatizar revisões técnicas.
- Automatizar validações de código.
- Facilitar a reutilização de soluções já implementadas.
- Centralizar prompts, templates e checklists.
- Criar ferramentas que auxiliem no desenvolvimento utilizando IA.
